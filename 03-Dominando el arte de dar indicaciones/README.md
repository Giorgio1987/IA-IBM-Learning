# ✍️ Dominando el arte de dar indicaciones (Prompt Engineering)
Este módulo se enfoca en la comunicación efectiva con modelos de IA Generativa.

### 📝 Estrategias aprendidas:
* **Contexto:** Darle un rol a la IA (ej. "Actúa como un experto en ciberseguridad").
* **Claridad:** Instrucciones directas y sin ambigüedades.
* **Iteración:** Cómo mejorar una respuesta mediante el refinamiento del prompt.
* **Formatos de salida:** Pedir resultados en tablas, código, listas, etc.
