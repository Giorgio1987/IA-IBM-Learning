# 🚀 Ruta de Aprendizaje: Inteligencia Artificial (IBM SkillsBuild)

¡Bienvenidos! En este repositorio documento mi progreso, apuntes y certificaciones obtenidas a través de la formación gratuita de **IBM SkillsBuild** sobre Inteligencia Artificial. 

El objetivo es construir una base sólida en IA, desde los conceptos teóricos hasta la aplicación práctica de modelos generativos y el diseño de prompts.
